# Gate × IC 手机行情观察

个人只读行情看板，部署到 GitHub Pages。分别显示 Gate / IC 价格、15m/1h/4h 方向、动能评分、量比/Tick 比、机会状态及有效的观察区间。

## 免费 Gate 直连

手机浏览器直接读取 Gate 官方公开 API，并在页面中计算 EMA、ATR、成交额量比、动能及机会筛选。**电脑关闭也能更新 Gate**；页面在前台时每 60 秒分析一次。首次载入历史约 20–40 秒，网络较慢可能更久。关闭页面、手机锁屏或切到后台后暂停，返回时重新分析；这不是全天后台云监控，也不发送后台交易提醒。

固定保留 BTC、ETH、SOL、UNI、HYPE、ZEC、XRP、DOGE、BNB、NEAR、LTC、SUI；连同另外 10 个候选一起筛选，最多补充 3 个符合规则的品种。规则保存在 `dist/gate-config.json`。固定名单不会因暂未达标而消失。

所有接口均为匿名公开 GET，无交易权限、API 密钥或账户接口。手机需能访问 Gate 官方 API；地区限制、网络、接口限流或时间异常时暂停。源行情超过 150 秒、计划到期、触及止损/首个目标时，不再展示有效入场计划。评分不是胜率，条件满足仍需人工核对。

## 动态设置

点网页右上角 **设置**，可修改上涨/多头与下跌/空头颜色、动能分级起点，以及流动性、价差、涨跌幅、资金费率、上市时长、量能、ATR、止损、费用和扣费后盈亏比阈值。

默认红涨绿跌，动能分级起点 20/40/70。分级只影响强弱显示，不改变评分公式。修改筛选规则后立即停用旧计划并重新计算。设置仅保存在当前浏览器；清除浏览器数据会重置设置。

终端同样支持本机热更新，按 **s** 修改。网页与终端设置分别保存，不自动同步。当前电脑已安装；公开补丁和说明见 `desktop/`，不含本机设置或私人仓位。

## IC 数据链路

IC 仍由电脑运行 MT5 → `export_snapshot.py` 白名单导出 → `publish.py` 每约 20 秒更新 `feed` 分支时间快照 → 页面约每 10 秒读取。仅保留最近 20 个文件，用独立文件名避开可变原始文件缓存。电脑离线只影响 IC，不影响 Gate 直连；网页从不将 IC 同步中的 Gate 报价用作备用。

IC 报价超过 45 秒即暂停。Tick 比是经纪商报价活跃度，不是交易所成交量。IC 结构筛选与费用确认保持电脑脚本管理。

仅网页、公开代码和行情白名单上传仓库。交易账号、个人仓位、盈亏、截图、本地路径、凭证不导出。`publish.py` 使用已有 GitHub CLI 登录，不把令牌放进页面。

## 本机 IC 同步

在被 Git 忽略的 `.local/publisher.json` 配置：

```json
{"repository":"OWNER/REPOSITORY","source":"/absolute/path/to/combined/snapshot.json"}
```

运行 `python3 publish.py --watch`。进程锁防止重复同步；失败等待下轮，不改变原监控。IC 来源配置为 `dist/config.json`；`feed` 更新不触发网站部署。

## 验证

`npm test` 覆盖 Python 策略的 14 组模拟行情对照、计划失效、来源隔离、设置校验及公开请求限制。`python3 -B -m unittest discover -s tests` 检查导出隐私、同步和本机设置隔离。模拟数据位于测试目录，不作为行情使用。
