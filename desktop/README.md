# 本机终端设置

`monitor.patch` 是原 Gate_MT5_Monitor 项目的只读显示与筛选补丁。此次更新已安装到当前电脑；该目录仅存公开源文件，不含本机配置、账户或仓位。

终端重新打开后，按 **s** 进入编号菜单：**1 红涨绿跌、2 绿涨红跌、3 分别选择常用颜色、4 动能分级、5 Gate 筛选**，输入 **0** 保存，**q** 放弃整次修改。常用颜色无需输入色值；选择自定义颜色时才填写。也可双击原项目根目录的 `configure_display.command`，直接加载最新菜单。

设置写入本机 `mt5/monitor_settings.json`，终端显示及 MT5 面板热更新，Gate 在下一轮（约 60 秒）重新计算。新规则尚未计算时暂停旧计划。修改分级只改变强弱显示，不改变评分公式或入场条件。IC 的结构筛选规则保持原有脚本管理。

网页设置保存在当前浏览器；两端分别管理，不自动同步。默认红色上涨/多头、绿色下跌/空头；默认动能起点为 20/40/70。

其他电脑安装时，先备份原项目，核对补丁适用版本，用 `git apply --check monitor.patch` 检查后应用，再把本目录的 `monitor_settings.py`、`settings-schema.json` 复制到项目 `mt5/`。MQL 源码需在 MetaEditor 编译后安装并重新加载指标。
